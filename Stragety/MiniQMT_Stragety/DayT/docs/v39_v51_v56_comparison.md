## 三、核心机制逐项对比

### 1. 卖出触发机制

**v39：简单回撤触发**
```
触发条件：价格 ≥ 开盘价 × (1 + ATR% × 系数)
卖出条件：从最高点回撤 ≥ 0.5%~0.6%
```
- 系数由趋势/波动率/量能/RSI四因子计算得出
- 回撤阈值较固定（约0.5%）

**v51：分钟强度动态调整**
```
触发条件：价格 ≥ 开盘价 × (1 + ATR% × quantile_units × 0.60)
卖出条件：从最高点回撤（与强度相关）
```
- 强度分量1：开盘偏离度（0.25 ATR时满格）
- 强度分量2：日内均价偏离度（0.10 ATR时满格）
- 强度分量3：10分钟动量（0.10 ATR时满格）
- 平滑后强度≥0.8时，降低的触发阈值会恢复到原始值

**v56：更严格反转确认**
```
触发条件：价格 ≥ 开盘价 × (1 + ATR% × quantile_units × 0.60)
反转确认：至少2根K线，涨幅≥0.15%，回撤≥0.20%
卖出条件：从最高点回撤（与强度相关）
```
- 比v51多一个"反转确认"门槛：必须看到明确的回落信号才行动
- 回撤确认要求更高（0.20% vs v51的动态回撤）

### 2. 买回机制

**v39：固定ATR比例买回**
```
买回价 = 卖出价 × (1 - ATR% × 0.15)
紧急买回：价格 ≥ 卖出价 × 1.03 时强制买回
```

**v51/v56：统一ATR比例买回（与v39相同基础逻辑）**
```
买回价 = 卖出价 × (1 - ATR% × 0.15)
```
- 但有强度观察窗口：买回前需观察近期低点和反弹确认
- 反弹确认：从低点反弹0.8%~2.0%才执行

### 3. 动量（MOM）策略

**v39：完整MOM系统**
- 2分钟涨幅 ≥ ATR阈值 → 触发冲高做空/抄底反弹
- 每日最多3次MOM交易
- 冷却等待：首次12秒，每次减2秒
- 与REV-T有优先级冲突保护（REV-T优先）

**v51/v56：完全禁用MOM**
```
MOM_ENABLED = False  # MOM已屏蔽
```

### 4. 风险控制

**v39：涨停板保护 + 5次上限**
- 涨停板附近（+9.5%）锁定新交易
- 涨停回落后120秒才解锁
- 反T最多5次/天，正T最多5次/天

**v51：无额外熔断**
- 依赖强度观察和影子模式保护

**v56：三重保护**
1. **3日涨幅熔断**：3日涨幅超阈值时阻止反T（如601869涨幅+6.03%被阻止）
2. **核心持仓保护**：未平数量/原始底仓 ≤ 50%
3. **方向准入门槛**：候选方向仅0/0.20/0.40，防止过度交易

## 四、通俗易懂的总结

### v39 — "激进短线客"
- **优点**：交易频率高，单日能抓住多次机会（一天最多7-8笔）
- **风险**：MOM追涨杀跌会带来较大亏损（如止损¥844）
- **适合**：震荡行情，股价波动大
- **问题**：没有组合保护，单股ALL IN风险集中

### v51 — "观察者/保守派"
- **优点**：用分钟强度做更精细的入场判断，有15分钟观察窗口
- **风险**：影子模式下不做实盘，需要人工验证后才能启用
- **适合**：验证阶段，观察新信号系统的有效性
- **问题**：无法产生实际收益，仅做观察记录

### v56 — "风控优先的稳健派"
- **优点**：三重风控（涨幅熔断 + 持仓保护 + 方向准入），安全性最高
- **风险**：交易机会大幅减少（3日涨太多就不做，持仓接近上限就不做）
- **适合**：大资金稳健运行，防止极端行情亏损
- **问题**：目前正T通道被禁用，交易方向单一
