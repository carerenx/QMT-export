# 策略研究方向与效果记录规则

本规则适用于 `Stragety/` 下每一种可独立比较版本的策略类型。每个策略类型维护自己的 `StrategicResearchDirectionsAndEffectivenessRecords.md`，用于记录研究方向、版本变更、验证证据和最佳版本。

## 一、策略类型与文件位置

- “策略类型”是具有相同目标、核心交易逻辑和统一比较口径的一组策略版本。
- 记录文件放在该策略类型各版本最近的公共目录中。
- 不同目标或无法使用同一评价口径的策略必须分开记录。例如 Long 与 DT 应分别维护记录。
- 一个目录中存在多个互不相关的策略族时，应建立子目录分别记录，不能用一份记录强行比较。
- 尚无研究活动的策略类型无需创建空文件；首次研究或变更时再创建。

## 二、何时更新

- 新增研究方向、新机制或新策略版本时，新增一条记录。
- 只调整参数、阈值或已有机制时，在原版本记录下追加一次实验；只有形成需要长期保留的独立版本时才新增版本记录。
- 修改策略代码但未完成验证时，状态只能标为 `待验证`。
- 放弃、失败或无效的方向也必须保留，并写明原因，避免重复研究。
- 更新最佳版本时，必须同时更新记录文件顶部的“当前结论”。

## 三、研究状态

每条记录只能使用以下一种状态：

- `构想中`：只有研究假设，尚未实现。
- `待验证`：已经实现，但验证尚未完成。
- `有效`：通过约定验证，相对基准有明确改善。
- `无效`：未达到目标，或改善不足以抵消副作用。
- `不具可比性`：数据、区间、费用或账户模型等口径不同。
- `已淘汰`：曾经有效，但已被适用范围相同且证据更充分的版本替代。

## 四、可比性要求

只有以下条件一致，版本之间才允许直接比较并判断优劣：

- 标的与股票池；
- 数据来源、复权方式、K 线周期和回测区间；
- 初始资金、初始持仓和连续账户状态；
- 手续费、印花税、滑点和成交规则；
- T+1、涨跌停、停牌、最小交易单位和部分成交规则；
- 信号生成时间与成交价格口径；
- 基准版本及评价指标。

任一条件不同，必须标为 `不具可比性`，不得据此更新最佳版本。

## 五、研究方法

- 每次实验原则上只验证一个主要假设。
- 多个机制同时变化时，必须注明无法归因，或补充分项消融实验。
- 实验前填写研究假设、预期改善、主指标和可能代价；不得根据结果倒推目标。
- 结论必须附可复现证据，例如回测命令、结果文件、报告或 Git commit。
- 不覆盖旧记录。结论改变时追加更正说明，并保留原结论及更正日期。
- 回测通过只代表历史样本验证，不代表未来收益，也不代表允许实盘运行。

## 六、最佳版本判定

- “最佳”必须限定评价范围，例如全样本、样本外、震荡期、趋势期或严格连续账户。
- 候选版本必须先通过执行安全和数据完整性检查，再比较收益表现。
- 以实验前声明的主指标判断改善，同时检查最大回撤、交易次数、换手率和成本敏感性等副作用。
- 主指标改善但风险显著恶化时，不得自动标记最佳，必须记录取舍并等待人工确认。
- 优先采用样本外、滚动验证和不同市场阶段均较稳定的版本。
- 单一区间偶然领先不足以成为最佳版本。
- 若证据不足或不同指标互有胜负，保留多个“候选最佳”，不得强行选出唯一版本。

## 七、命名与代码关系

- 策略文件遵循 `{策略名}_{版本}_{变更点或优化点}.py`。
- 新机制创建新策略文件；仅修改参数或优化已有机制时，在原策略上继续研究。
- 新策略不得导入同级旧策略文件，可以复用 `config`、`core`、`util` 中的公共代码。
- 每条记录必须填写策略文件路径；有代码提交时同时填写 commit 哈希。

## 八、策略类型记录文件模板

```markdown
# {策略类型}研究方向与效果记录

> 记录规则：[`Stragety/STRATEGY_RESEARCH_RECORD_RULES.md`](相对路径)

## 当前结论

- 当前最佳版本：待确认
- 适用评价范围：待确认
- 基准版本：待确认
- 最后更新时间：YYYY-MM-DD
- 说明：统一口径验证完成前，不标记最佳版本。

## 研究记录

### YYYY-MM-DD｜策略名｜版本｜研究方向

- 状态：构想中 / 待验证 / 有效 / 无效 / 不具可比性 / 已淘汰
- 策略文件：`相对路径`
- 基准版本：版本或文件名
- 研究假设：为什么这项改变可能有效
- 主要变更：只写本次实际改变
- 预期改善：预先声明的主指标和预期方向
- 可能代价：可能恶化的风险或场景
- 验证口径：标的、区间、数据、资金、费用、滑点、成交与账户规则
- 复现命令：`可直接执行的命令`
- 证据：结果文件、报告路径或 commit 哈希
- 结果摘要：同时列出基准值和候选值
- 分市场阶段结果：趋势 / 震荡 / 下跌，或说明未验证
- 结论：保留、继续验证、回退或淘汰
- 最佳版本影响：替代原最佳 / 候选最佳 / 不影响
- 后续方向：下一项可独立验证的假设
```

新记录添加在“研究记录”顶部，使最新记录优先显示。
