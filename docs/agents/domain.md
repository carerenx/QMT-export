# Domain docs

This repository uses a single domain context.

Before changing architecture or domain behaviour, read:

- `/CONTEXT.md`, when present, for the project glossary and invariants.
- `/docs/adr/`, when present, for accepted architectural decisions.

Use terms exactly as defined in `CONTEXT.md`. If a necessary concept is absent,
add it only when the design resolves its meaning. Surface any proposal that
contradicts an ADR instead of silently overriding the decision.
