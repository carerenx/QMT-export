## 策略交易流程说明

反T（先卖后买）：每天开盘后计算触发线，盘中触发后按状态机执行：

```
IDLE → 价格触及触发线 → SPIKING → 价格从最高点回落0.1% → 【卖出1手】
  ↓
SOLD → 价格跌到卖出价×(1-ATR%×0.15) → DIPPING → 价格从最低点回升0.1% → 【买回1手】
  ↓
DONE（当日不再交易）
```

- **操作1=卖出 (SELL)**：价格冲高后回落确认，在接近日内高点处卖出
- **操作2=买回 (BUY)**：价格回落后企稳反弹，在接近日内低点处买回
- 如果卖出后价格不跌反涨超过紧急阈值，触发**紧急买回（亏损）**
- 尾盘 14:57 仍未买回则**强制买回**
